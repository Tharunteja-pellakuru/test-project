# eParivartan Premium Agency Case Study Portfolio

This repository contains the interactive and premium Work page (`work.html`) for eParivartan, matching the aesthetic and performance benchmarks of top-tier design agencies.

## Features

1. **Interactive Case Studies**: Detailed scrolling storytelling layout (Challenge → Research → Design → Dev → Results).
2. **Real Device Chassis Mockups**: Interactive rendering in realistic MacBook Pro, iPad Pro, and iPhone 16 Pro chassis.
3. **Before/After Draggable Slider**: Sweep comparison showing visual upgrades.
4. **Animated Lighthouse Gauges**: Real performance, SEO, accessibility, and best practices circular SVGs.
5. **Interactive growth curves**: Curve graphs drawn in real-time SVG paths.
6. **Live Preview Modal**: Full-screen sandbox browser window with mac traffic lights controls and pulse live dots.
7. **Client logos marquee & live ticker**: Ticking project counters and infinite marquees.
8. **Responsive designs & Light/Dark themes**: Supported on all devices.

## Running Locally

To load dynamic case studies from `projects.json`, serve files via a local HTTP server:

```bash
# Python http server
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000/work.html`.
